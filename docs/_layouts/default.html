THREE CHANGES, all required because this is ONE build serving two languages: 1. The html element read `site.lang`, a single site-wide value, so every French page declared itself English. It now reads `page.lang` first. 2. The skip link text was hardcoded English. It now follows the page language. 3. A language toggle is rendered at the top of the main content, linking each page to its counterpart through the `lang_ref` front matter key. It lives here rather than in the sidebar because the sidebar is `include_cached` and so cannot vary per page; see _includes/head_custom.html for that argument in full. The link text is in the TARGET language, which makes it a change in the language of a part, so it carries both `lang` and `hreflang` (WCAG 3.1.2), matching the marking discipline in components/nav/links.html. This override is pinned to theme internals (finding BLD-M7).
